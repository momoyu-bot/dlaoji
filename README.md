# 打捞机

从 Grok 导出的 `prod-grok-backend.json` 里，把做过的小文件捞回来。

- 完整 HTML 网页
- JSX / TSX（沙盒里能玩、本身不是网页的「明珠」）
- 列表名字优先用**你说过的中文**，不看 Grok 的英文小标题

## 用法

1. 下载 [打捞机.html](./打捞机.html)（或 [dlaoji.html](./dlaoji.html)，内容相同）
2. 用电脑浏览器打开这个 HTML（Chrome 最稳，一百多 MB 的 json 别用手机）
3. 把 `prod-grok-backend.json` 拖进去
4. 默认「只看网页」；要找漏网的 JSX，点「只看明珠」
5. 搜索框直接打你记得的中文，比如「羊」「睡」「跟读」

文件不会上传，全部在本机浏览器里完成。
